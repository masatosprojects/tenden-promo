Problem

なぜ観光客は
逃げられないのか

土地勘のない観光客と地元住民の生存率には 53.6 ポイントもの格差がある。 シミュレーションにおいて地域住民の生存率が 85.1% に達する一方、 一般来訪客はわずか 31.6% にとどまった。

その主因は三つ——ナビゲーションの失敗（地図なし時、60% の確率で誤経路選択）、 避難開始の遅れ（来訪客の 70% が発災後 5 分以上待機）、 そして海岸出口の交通渋滞だ。

さらに逆説的な発見がある。ハザードマップの普及率を 100% にすると、 全員が同一の「最適ルート」に殺到して混雑が激化し、 むしろ全体の生存率が6.1 ポイント低下する—— 混雑の罠（Congestion Trap）と呼ばれる現象だ。

Features

研究知見を実装した
7 つの機能

シミュレーションが明らかにした「混雑の罠」を回避するために、TENDEN は静的なマップではなく動的な3ルート案内を提供する。

🔀

3 ルート同時提示

最短距離・混雑回避・バリアフリー平坦の 3 候補を OSRM + シミュレーション混雑データで同時計算。ルート選択の主体はユーザー自身に委ねる。

📡

津波警報 自動検知

P2P 地震情報 WebSocket（api.p2pquake.net）に常時接続。JMA コード 551/556 で即座に緊急モードへ移行し、切断時は 5 秒で再接続。

🌊

公式浸水想定タイル

国土地理院ハザードマップポータルの津波浸水想定タイルをオーバーレイ。Canvas ピクセル解析で現在地の区域内外を HUD にリアルタイム表示。

🌐

ゼロクリック多言語

ブラウザ言語を自動検知し、日本語・英語・中国語（簡体）・韓国語へ即時切り替え。一般来訪客の 53.6pp 死亡格差に応えるための最優先機能。

📶

オフライン PWA

Service Worker でマップタイル・JSON データ・UI アセットを動的キャッシュ。通信インフラ被災後も動作継続。インストール不要でホーム画面追加が可能。

♿

バリアフリールート

年齢別格差（成人 41.2% vs 高齢者 30.8%）の根拠に基づき、坂・段差を考慮した平坦優先ルートを高齢者・乳幼児連れに明示する。

📤

ワンタップ安否共有

Web Share API で現在地 Google マップ URL と安否メッセージを家族・友人へ即送信。緊急時に複雑な操作を必要としない設計思想。

Research

ハザードマップ逆説

25 シナリオ・50 試行の感度分析が示した、最も反直感的な発見。 情報の均一化が、かえって集合的な死亡率を高める。

D 群 — ハザードマップ認知率変動シナリオ Congestion Trap

D1 — 認知率 100%（全員最適ルートを把握）

35.8%

全員が同一の指定避難路へ収束。出口ノードに混雑が集中し、 Klüpfel 混雑指数が限界密度の 33 倍に達して歩行速度が 90% 低下。 一般来訪客の生存率は 29.4% まで急落。

D5 — 認知率 0%（全員ランダム分散）

41.9%

60% 誤認で来訪客が複数経路に偶発的に分散。混雑集中が緩和され、 逆説的に全体生存率が 6.1pp 上昇。 一般来訪客の生存率は 36.8% と認知率 100% 時より改善。

示唆：静的なハザードマップの普及率を高めるだけでは不十分。 個々人が合理的に「最適経路」を選択した結果として、集合的に非効率な混雑状態が発生する Braess パラドックスが鎌倉の道路ネットワーク上で定量的に観測された。 リアルタイムの混雑状況を反映した動的経路誘導こそが逆説の解消策である。
