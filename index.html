Concept

平時の「知る」を、
非常時の「生きる」に。

日常からシームレスに繋がる2つのモード。普段はハザード情報を学び、地震・津波発生の瞬間に自動切り替えで避難を案内する。

🗺️

平時モード

海抜・浸水想定区域・避難所を地図上で確認できる学習モード。 GPSによる現在地表示と標高リアルタイム取得で、旅行中でも 「今どのくらいの高さにいるか」を常に把握できる。 スクリーンショット保存でオフライン時の備えにも。

ライトモード / 海抜 HUD 表示
🚨

緊急モード

P2P 地震情報 WebSocket が大津波警報を検知すると自動起動。 ダークモードに切り替わり、シミュレーション統計に基づく 3ルート候補（最短 / 混雑回避 / バリアフリー）を即座に提示。 ルート逸脱を振動・点滅で警告し、安否共有も1タップで完了。

緊急ダークモード / 3ルート案内

Features

研究知見を実装した
7つの機能

🔀

3ルート同時提示

最短距離・混雑回避・バリアフリー平坦ルートの3候補を OSRM + シミュレーション混雑データで同時計算。最終判断はユーザーに委ねる設計。

🌊

公式浸水想定タイル

国土地理院ハザードマップポータルの津波浸水想定タイルをオーバーレイ表示。Canvas ピクセル解析で現在地の区域内外を HUD にリアルタイム判定。

🌐

ゼロクリック多言語

ブラウザ言語を自動検知し、日本語・英語・中国語（簡体）・韓国語へ即時切り替え。土地勘のない外国人観光客が主要ターゲット。

📡

津波警報自動検知

P2P 地震情報 WebSocket（api.p2pquake.net）に常時接続し、JMA コード 551/556「大津波警報」で緊急モードを自動起動。切断時は5秒で再接続。

📶

オフライン PWA

Service Worker でマップタイル・データ・UI を動的キャッシュ。通信インフラ被災後もアプリが動作し続けるよう設計。インストール不要でホーム画面追加が可能。

♿

バリアフリールート

シミュレーションが示す年齢別格差（成人 41.2% vs 高齢者 30.8%）を踏まえ、坂・段差を考慮した平坦優先ルートを高齢者・乳幼児連れ向けに明示。

📤

ワンタップ安否共有

Web Share API で現在地 Google マップ URL と安否メッセージを家族・友人に即送信。緊急時にフォームを操作する認知負荷ゼロの設計。

Research Background

シミュレーションが示す
2つの核心発見

発見 1 — 属性間格差

53.6pp

地域住民（85.1%）と一般来訪客（31.6%）の生存率差。 土地勘・初期危機感・避難ケース分布の違いが、 短いリードタイムで命の分岐点を生み出す。

発見 2 — ハザードマップ逆説

−6.1pp

ハザードマップ認知率 100% 時の生存率低下幅。 全員が同一の「最適経路」に収束し、混雑の罠（Congestion Trap）が発生。 動的ルーティングが逆説解消の鍵。

感度分析ランキング（生存率変動幅）

人口・季節構成 (B群) 32.1pp
津波到達時間 (A群) 31.4pp
ハザードマップ認知率 (D群) 6.1pp
率先避難者割合 (E群) 1.5pp
警報タイミング (C群) 1.0pp

物理的制約（人口規模・到達時間）が情報・行動系介入の20倍以上の影響力を持つ。 単独介入の限界が動的統合システムの必要性を示す。
