Name Origin

「てんでんこ」の教え

津波てんでんこ

三陸地方に伝わる津波防災の教訓・標語

「津波が来たら、
てんでんこ（各自で）逃げろ」

「てんでんこ」とは三陸地方の言葉で、「それぞれ・各自」を意味します。 津波が来たら家族や周囲を顧みず、各自が素早く高台へ逃げることが 全員の命を守るという先人の知恵から生まれた教訓です。

TENDENは、この教え—— 一人ひとりが自ら判断し、自ら逃げる—— をデジタルで実装したアプリです。 鎌倉モデル地区のみならず、日本全国すべての沿岸部で機能するようにシステムが拡張されており、どこにいても最適な「3つの避難候補ルート」をあなたに提示します。

The Problem

Why can't tourists escape?

同じ津波なのに、地元住民と観光客で

土地勘がなく避難経路を知らない観光客は、発災直後に立ち往生しやすく、 誤った方向へ走ってしまうことも珍しくありません。

さらに深刻な問題があります。全員が同じ「安全そうな最短ルート」を目指すと、 そこに人が殺到して身動きが取れなくなる—— 「混雑の罠」です。 研究では、全員が同じルートを知っていると知らない場合より 生存率が下がることも確認されました。

TENDEN's Approach

How TENDEN helps

「分散」こそが
全員を救う

TENDENが提案するのは「3ルート同時提示」による避難者の分散です。 最短距離ルートだけでなく、シミュレーション結果や道路混雑を評価した迂回ルートと、 傾斜や段差を考慮したバリアフリールートを同時に地図上に描画します。

また、このような複雑な避難シミュレーションを全国すべての沿岸自治体で行うのは現実的ではありません。そこでTENDENは、 「全国一般化自動ハザードスキャニング」を新搭載。国土地理院ハザードマップと連動し、ユーザーのGPS位置から動的に10km四方をスキャン処理することで、日本のどこにいても鎌倉モデル地区と同様の高精度な避難誘導をその場で生成可能にしました。

スマートフォンがあればインストール不要ですぐに起動（PWA）。画面消灯防止（Wake Lock）やOSネイティブのバックグラウンド警告通知、スマートコンパスと指向性矢印など、スマホのハードウェア機能を極限まで活かして命を守ります。

🟢

混雑予測を自律的に迂回する最短ルート

シミュレーションによって可視化されたボトルネック混雑予測レイヤーを分析し、渋滞が起きるメイン道路を能動的に迂回した最短経路をスナップ生成します。

🔵

避難所の収容限界を回避する分散ルート

避難所ごとの現在の満員度（low/medium/high）をリアルタイム判定。キャパシティ超過で入場拒否（二次渋滞）が起きそうな危険ポイントを避け、余裕のある安全な避難所へあなたをスマートに導きます。

🟣

地形から坂道を避けるバリアフリールート

標高メッシュから車いすや高齢者・児童の歩行を遮る「急勾配な坂道」を自動検出して排除。HUDにそのルートの「アプローチ最大勾配角度」を数値で表示し、パーソナライズされた到達予想時間を算出します。

🛟

11

🛡️ Canvasピクセル解析による高精度ハザード侵入判定

TENDENは、国土地理院が配信する広域津波ハザードマップ（PNGタイル画像）を、メモリ上に不可視に生成したCanvasへマッピング。現在地の1ピクセルをRGBAカラーコード単位でミリ秒解析します。

これにより、サーバー通信を行わずに「現在地がハザードマップの浸水指定域の中か外か」を1pxレベルの誤差なく判定。浸水域に入った瞬間に、HUDに赤く脈動する危険アラートを点滅表示させ、スマホ通知を強制起動させます。

🛰️ 電波不要の全国対応オフライン重心 Centroid スキャン

オフライン環境（通信障害・基地局倒壊時）でもハザードデータを読み込めるよう、TENDENは日本国内の主要沿岸県の重心（Centroid）座標を用いた超軽量な距離最小化判定アルゴリズムを内蔵。電波が全くなくても、瞬時に最寄りの県のハザードマップを自動ローカルキャッシュから切り替えます。

📲 スマートフォン固有の5大極限API連携アーキテクチャ

Screen Wake Lock API 🔒

避難移動中の自動画面スリープを強制防止。GPSのバックグラウンド制限（スロットリング）による測位遅延や、画面消灯によるルート確認の中断をゼロにし、常時HUD表示を維持します。

Vibration API (Haptic Touch) 📳

すべての操作時の触覚フィードバック（15msの精細振動）に加え、ルートから100m以上「逸脱」した際、および津波危険エリアへ「進入」した際の警告振動パターンを物理的に指先に伝えます。

Notifications API 🔔

ブラウザを閉じている、あるいはスマホをポケットに入れているバックグラウンド状態でも、危険検知時にOSネイティブの緊急バナーアラートを強制発報。電池消耗を防ぐ12秒リミッターを装備。

Device Orientation API 🧭

内蔵の3軸ジャイロおよび磁気センサーと1秒間に数十回同期. ユーザーの向いている方角を「視野コーン」として照射し、現在地の青ピン上にApple風の「指向性向きドット」を正確に重ね合わせます。

Battery Status API 🔋

避難中の最も致命的な「スマホの充電切れ」を防ぐため、バッテリー残量20%以下を検知すると自動的に緊急節電アラートを発動. GPSの間引き測定や輝度警告を行い、駆動時間を延ばします。

Research Background

What the simulation revealed

「情報が多いほど
安全」は本当か？

鎌倉市沿岸の大規模シミュレーション研究が明らかにした、直感に反する避難行動の真実。

全員が同じルートを知っている場合

生存率↓

全員が「正しいルート」を知っていると、そこに人が殺到。 避難所の入口や道路が混雑して身動きが取れなくなり、 誰も避難経路を知らない場合より生存率が下がったという衝撃的なシミュレーション結果が出ました。

バラバラに逃げた場合

生存率↑

誰がどこへ逃げるか「意思決定」が分散していると、ルート上の混雑が緩和され、 全体としてより多くの人が助かることが物理的に確認されました。 「正解」を画一的に共有することが、必ずしも被災時の最善ではありません。

TENDENの答え

だから、TENDENは3つのルートを同時に見せる。
「どれが自分にとって正しいか」を決めるのはあなた自身。
その各自の『てんでんこ（自律判断）』が、全体の生存率を押し上げる。
