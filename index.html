Evacuation Philosophy

「各自で判断し避難する」という基本方針

津波てんでんこ

三陸沿岸部に伝わる、迅速な主体避難を促す防災教育の知見

「津波襲来時には、周囲の状況を注視しつつ、
各自が迅速に安全な高台を目指すこと」

「てんでんこ」とは、それぞれが他者の判断に過度に同調せず、自ら責任を持って避難行動を起こすことが、結果として全体の生存性を高めるという先人の経験則に基づく防災方針です。

TENDENはこの方針をシステム設計として実装。全員を一律の「単一の推奨ルート」に導くのではなく、避難者自身の特性や周辺の想定に基づいた「3つの代替経路」を提示することで、各自の主体的な判断による避難をサポートします。

The Solution

Autonomous Route Diversification

避難経路の選択における
自律的な分散効果

TENDENは、最短ルートに加えて、シミュレーションに基づく混雑想定を回避する迂回ルート、および**道路の勾配特性を考慮したバリアフリールート**を動的に同時提示します。

日本全国の多種多様な沿岸エリアに対応させるため、本アプリは「広域ハザード自動算定アルゴリズム」を新設計。GPSの位置情報を基に、周囲約10km四方の地形・標高および自治体避難所データを動的照合し、通信制約下でもその場で避難候補エリア（第一目標）を算出します。

PWA仕様のためスマートフォンのブラウザさえあれば即時起動。スリープ防止（Wake Lock）や、ジャイロ連動による方向指標など、標準Webテクノロジーのみで自律的な避難動作の継続をサポートします。

Route Architecture

Three analytical routes

歩行者特性や周辺状況を反映した
3つのサポート経路

TENDENは、道路形状に完全にフィッティングした明瞭なルートラインで表示され、視界が悪い状況や夜間における見やすさを重視しています。

🟢 最短・混雑回避ルート
🔵 避難所負荷分散ルート
🟣 地形勾配配慮ルート
🟢

混雑想定エリアを迂回する最短ルート

シミュレーションで可視化されたボトルネック混雑予測レイヤーを参照し、道路上の滞留が予想される主要道路を自律的に迂回した推奨経路を提案します。

🔵

避難所の収容過多を抑える分散ルート

目的となる避難所の予測利用率（low/medium/high）を動的に判断し、許容量を超えそうな主要施設を避け、比較的余裕のある代替の安全な避難所へ案内します。

🟣

急勾配の坂道を自動で避ける勾配配慮ルート

標高数値地図から高齢者・要介助者の歩行を阻む急坂を自動検出。HUDにルートの最大勾配情報を提示し、歩行特性（速度）に応じた現実的な所要時間を算出します。

Technology Core

Web Technologies For Disasters

被災時における安定した
自律アルゴリズムの適用

🛡️ Canvas APIによる津波浸水想定区域のローカル判定処理

TENDENは、国土地理院が配信する広域津波ハザードマップタイルをメモリ上の非表示Canvas領域に展開。現在地（GPS座標）に対応する1ピクセルのRGBAデータをミリ秒単位で判定します。

この処理により、外部サーバーとの往復通信を行わず、「ハザードマップ指定域への侵入」を1ピクセル精度で自律的かつ即座に判定。インターネットが途絶した環境でも機能します。

🛰️ 電波障害を想定した全国対応のオフライン重心 Centroid 判定

オフライン環境においても日本全国47都道府県の境界・地形データをローカル処理で参照するため、主要沿岸県の重心（Centroid）座標からの距離最小化アルゴリズムを導入。電波が一切ない状況下でも、最寄りのハザードマップを自動的に選択します。

📲 スマートフォンにおける5つの主要なWeb標準技術（API）の連携仕様

Screen Wake Lock API 🔒

移動中の不要なスリープを防止。GPSのバックグラウンド測位制限（スロットリング）によるデータ途絶や画面消灯を排除し、情報提示を円滑に維持します。

Vibration API 📳

画面を凝視できない状況や手元が揺れる環境を想定し、15msの精細な確認用ハプティクス振動のほか、ルート逸脱・危険域侵入時の警告通知を指先に伝えます。

Notifications API 🔔

アプリ起動状態でないバックグラウンド時でも、GPSに連動して危険判定時にOS標準のバナー通知を発行。電池消耗を抑えるための12秒制御リミッターを装備。

Device Orientation API 🧭

内蔵の3軸ジャイロ・磁気センサーとミリ秒レベルで同期。避難者の向きを進行コーンとしてマップ上に投影し、現在地ピンにApple風の向き追従ドットを正確に反映します。

Battery Status API 🔋

避難移動時のスマートフォンの電源切れを防止するため、バッテリー残量20%以下を検出すると節電アラートを起動。画面輝度やGPSの測位頻度を調整します。

Research Background

Evacuation Simulation Data

避難情報の共有方法に関する検証

鎌倉市沿岸の地理的特性を反映した大規模シミュレーション分析が示す、避難効率と情報共有の関係。

一律に特定の同一経路を共有した場合

生存率↓

全員が単一の「安全と思われる最短ルート」へ集中すると、ボトルネックとなる避難所周辺の道路や交差点で大規模な滞留が発生。**生存率がかえって低下する可能性**がデータ解析から明らかになっています。

各自が自律して経路を分散選択した場合

生存率↑

避難者の意思決定や判断材料が自律的に分散している場合、特定箇所への過度な人流集中が能動的に緩和され、**エリア全体の安全性が高まる**という避難ダイナミクスが検証されています。

システム設計方針

TENDENが3つの異なる推奨ルートを提示する理由はここにあります。
「避難経路の選択権」を避難者自身に還元し、各個の自律判断をサポートすることが、結果として全体の生存性の最大化に寄与します。
